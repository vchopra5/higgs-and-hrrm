## Identity across the project

The README uses the full hero, local badges, and a forest/emerald system diagram. Setup, architecture, and backend guides share a logo masthead and home navigation. The presentation opens with the same banner. The Fabric display name, controls category, and mod icon also use HIGGS HRRM.

The original runtime identifiers (`higgs_villagers` and Java entrypoints) stay stable for compatibility.

## Palette

| Color | Hex | Role |
| --- | --- | --- |
| Forest | `#10251F` | Backgrounds and outlines |
| Emerald | `#76D59A` | Voice, interactions, and accents |
| Cream | `#F6EDCF` | Titles and primary text |
| Copper | `#D8A374` | Secondary accents and warm details |

Write the project name **HIGGS HRRM**, with a space and no “and” or ampersand. Use **Boson Higgs Realtime** when naming the voice technology.

Keep the artwork’s aspect ratio, leave clear space around the logo, and pair cream with forest for readable copy. Use the full banner where the title remains legible; use the logo for small placements. The logo is supplied as a transparent PNG. The wordmark uses blocky pixel lettering; document body copy uses the platform’s default font. For a new slide or page, use one strong title, generous spacing, and emerald accents rather than adding a new palette.

## Artwork notes

The banner and logo were created with the built-in ImageGen tool. The banner is illustrative brand art, not an in-game screenshot. The generated PNGs are stored in this repository, so the README does not depend on an external image host.

The [art direction and generation prompts](assets/prompts.md) are included for future revisions. The setup and implementation details live in the [setup guide](setup.md) and [architecture](architecture.md).
