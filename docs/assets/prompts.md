# Brand artwork prompts

Generated using the built-in ImageGen tool. These are the original generation prompts and the final banner edit. The first brief used the previous working name; the final artwork uses **HIGGS HRRM**. The logo contains no text.

## Hero · initial generation

```text
Use case: ads-marketing. Create a finished premium GitHub README hero banner for the Minecraft voice NPC project Higgs and Hrrm. Wide landscape 3:1 aspect ratio, ideal 1800x600. Art direction: sophisticated indie game launch identity, precision pixel art mixed with flat editorial layout, deep forest green background #10251f, warm ivory #f6edcf, emerald #76d59a and restrained copper accents. Left 55 percent: beautifully spaced large ivory pixel typography reading exactly 'HIGGS' on line one, 'AND HRRM' on line two. Smaller legible text below exactly 'Give the hrrm a voice.' Under that a small elegant kicker exactly 'VOICE-POWERED MINECRAFT VILLAGERS'. Right 45 percent: charming close-up voxel Minecraft villager with long rectangular nose, green eyes, brown unibrow, beige face and brown robe, emerging from an angular speech bubble frame, a small emerald and minimalist square sound-wave pixels floating nearby. Villager looks expressive and curious, subtle isometric cubic lighting but crisp pixel edges. Sparse tiny grid marks and pixel stars in background, ample negative space, strong contrast, beautifully balanced layout, high quality actual finished brand artwork. All typography fully inside generous safe margins. No UI mockups, no screenshots, no device frames, no extra words, no watermarks. This is illustrative brand artwork, not a depiction of the implemented gameplay.
```

## Hero · final name edit

```text
Use case: text-localization. Edit this exact GitHub brand banner. The project has been renamed to HIGGS HRRM. Change only the large title: line one must read exactly 'HIGGS', line two must read exactly 'HRRM'. Remove the word AND entirely. Rebalance both large title lines beautifully within the left-hand text region, with HRRM in the same large ivory pixel type and aligned with HIGGS. Keep the villager, speech-bubble frame, emerald, sound-wave symbol, forest, colors, lighting, aspect ratio and all other text exactly unchanged, including 'Give the hrrm a voice.' and 'VOICE-POWERED MINECRAFT VILLAGERS'. Preserve the original layout and premium pixel artwork. No other new elements or text.
```

## Logo · generation

A striking compact pixel-art emblem combining a villager face and an angular speech bubble silhouette, readable as an avatar at 48px. Face: beige rectangular head, iconic long blocky nose, two tiny forest-green eyes and thick brown unibrow, friendly understated expression. Bubble frame and tail: vivid emerald green #76d59a with deep forest green #10251f outline. Ivory #f6edcf highlights, warm copper/beige shadows. Flat 2D pixel geometry, crisp aligned square edges, strongly designed negative space, no soft 3D bevels, no gradients, no glow, no drop shadows, no tiny decorative details. Oversized mark centered with generous clear transparent margin. No letters, no words, no watermark, no surrounding scenery. Premium indie game identity, restrained palette, confident simple silhouette. Actual alpha transparency.
